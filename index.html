About Mental Health Detection

This project explores how student lifestyle and digital behavior variables can be used with machine learning to estimate a Mental Health Score.

  • Student lifestyle analysis
  • Social media behavior
  • Academic habits
  • Sleep patterns
  • Physical activity
  • Stress level
  • ML-based prediction
  • FastAPI deployment

This system is a machine-learning coursework project. It has not undergone clinical validation.

MindScope AI

Mental Health Detection — an educational machine learning project.

Important: This application is an educational machine-learning project and should not be used as a substitute for professional mental health assessment, diagnosis, or treatment.

No analytics trackers. No external databases. Data is sent only to the configured prediction API.
